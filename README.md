# Data Science Projects

Colección de algunos de mis proyectos académicos organizados por tema a partir de mis estudios de Ciencia de Datos.

## Proyectos

| Proyecto | Tecnología | Contenido |
|---|---|---|
| [Calidad del aire en Zamora](data-analysis/air-quality/) | R | Filtrado temporal, visualización e imputación mediante regresión lineal. |
| [Simulación de fiabilidad](probability/reliability-simulation/) | R Markdown | Exploración de distribuciones y tiempos de fallo en un ejercicio académico. |
| [Estimación bayesiana con conjugados](bayesian-analysis/normal-conjugate-model/) | R | Distribuciones previas, verosimilitud y actualización de una media normal. |
| [Análisis factorial de vinos](multivariate-analysis/factor-analysis/) | R Markdown | Matriz de correlación, adecuación muestral, extracción de factores y rotaciones. |
| [Regresión y clasificación](machine-learning/regression-classification/) | Python / Jupyter | Regresión lineal, regresión logística y evaluación de modelos. |
| [Cola de prioridad con montículos](data-structures/priority-queue/) | Python / Jupyter | Gestión de eventos y ordenación por prioridad con la biblioteca estándar. |
| [Canales de color y contraste](computer-vision/color-and-contrast/) | Python / Jupyter | Canales RGB, corrección gamma, transformación logarítmica y ecualización. |

## Cómo usar esta colección

Cada proyecto tiene su propio README con dependencias, entradas y limitaciones. Ejecuta los archivos desde su carpeta de proyecto. No hay un entorno común ni versiones de paquetes verificadas.

## Alcance y estado

El contenido refleja entregas académicas originales, no software de producción ni resultados científicos validados. Los programas no se han ejecutado de nuevo durante esta organización. Se conservan limitaciones del código original y se indican donde se han detectado.

Se han retirado las salidas y metadatos personales de los notebooks, y se han cambiado algunas rutas locales por rutas relativas. No se incluyen temarios, documentación administrativa, trabajos de grupo, archivos de configuración con secretos ni datasets o imágenes de terceros. Algunos proyectos necesitan que se aporten sus datos de entrada por separado.

No se ha añadido una licencia de reutilización: queda pendiente la elección del autor y la revisión de derechos de los materiales académicos.
