# Estimación bayesiana con conjugados

Distribuciones previas, verosimilitud y actualización de una media normal.

- Lenguaje: R.
- Archivo: [normal_conjugate_model.R](normal_conjugate_model.R).
- Dependencias identificadas en el código: R base. Versiones no fijadas porque no se dispone del entorno original.

## Entradas

No necesita ficheros externos.

## Uso

Ejecutar `Rscript normal_conjugate_model.R` desde esta carpeta, tras instalar sus paquetes.

Entrega académica conservada como muestra de aprendizaje. No se ha ejecutado de nuevo ni validado su corrección estadística. Se mantiene una constante de normalización escrita en el original. No se ha recalculado.
