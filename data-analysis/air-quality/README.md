# Calidad del aire en Zamora

Filtrado temporal, visualización e imputación mediante regresión lineal.

- Lenguaje: R.
- Archivo: [air_quality.R](air_quality.R).
- Dependencias identificadas en el código: readr. Versiones no fijadas porque no se dispone del entorno original.

## Entradas

Entrada esperada en esta carpeta: `calidad-del-aire-datos-historicos-diarios.csv`. No se incluyen datos ni imágenes de las asignaturas: su permiso de redistribución no está verificado.

## Uso

Ejecutar `Rscript air_quality.R` desde esta carpeta, tras instalar sus paquetes.
